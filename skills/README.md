# Portfolio Agent Skills (canônicas)

Skills **altamente específicas** para `interfaces/web`. Fonte de verdade: esta pasta. Cursor descobre via junction em `.cursor/skills/<nome>/`.

## Identidade alvo

Observabilidade · realtime · dashboards industriais premium · infra operacional · frontend engineering · UI cinematográfica · depth · motion sofisticado

**Referências:** Linear · Raycast · Warp · Datadog · Sentry · Retool

**Evitar:** Bootstrap · template SaaS · grids repetitivos · glow excessivo · motion exagerada · cards estáticos · UI flat

## Skills internas

Cada `SKILL.md` contém:

identidade visual · direção artística · princípios de motion · composição · spacing · tipografia · iluminação · profundidade · interação · acessibilidade · performance · responsividade · anti-patterns · exemplos (`examples.md`)
